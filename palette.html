Site palettes

The colors for each site, ranked, then any other colors found in its code. Use the arrows to try a different order: it is saved in this browser and every candidate and site page here follows it, so you can see it live. When you like it, Export order and send it to Claude. Every color is read from the site's own code on hackahobo.info: a CSS rule, or an original image file when the color only exists in a logo or background image. Under each color is the exact pixel it was read from: a 10× zoom with the pixel boxed, and the spot on the live page ringed. The captures are lossless and at the page's real size, so every pixel is the site's own color. ← Back to the candidates
